usage: nightly_desktops.py [-h] [--stable-draft]
                           [--draft-token-file DRAFT_TOKEN_FILE] [--now]
                           [--desktops DESKTOPS [DESKTOPS ...]]
                           [--config CONFIG]
                           [tag]

Unattended Tier 1 controller. Run on d69, never on the workstation. python3
tools/lab/nightly_desktops.py --now [vYY.MDD.N-nightly] python3
tools/lab/nightly_desktops.py vYY.MDD.N --stable-draft --draft-token-file PATH
Private configuration: ~/.config/putgd-nightly/config.json and github-token
(owned, mode 0600). config.json supplies repository, builders (ssh argv, root,
rows), and each row's golden, bootstrapKey, knownHosts, profile and package.
The user service calls this without --now: already published tags are skipped.
It first fast-forwards d69's checkout to origin/nightly, and the controller
brings every builder to that commit, so merged driver fixes need no deployment
step. The worker uses only existing lab
launch/install/recipes/collection/retirement. No compilation, map updates,
per-night commits, or visual approval step.

positional arguments:
  tag

options:
  -h, --help            show this help message and exit
  --stable-draft        manually test exact assets of a named stable draft;
                        save separate local acceptance receipts
  --draft-token-file DRAFT_TOKEN_FILE
                        owned mode-0600 token with push access for --stable-
                        draft; the unattended read-only token cannot see
                        drafts
  --now                 manual trigger, including rechecking the same release
  --desktops DESKTOPS [DESKTOPS ...]
                        recheck only these desktop names, profile names or
                        builder IDs; preserve other rows
  --config CONFIG
