#include <algorithm>
#include <iostream>
#include <numeric>
#include <string>
#include <vector>

struct Sample { std::string label; int width; int height; };
int main() {
    const std::vector<Sample> samples = {
        {"garden", 640, 480}, {"river", 800, 600}, {"valley", 1024, 768}
    };
    std::vector<int> areas;
    // Read each synthetic sample and preserve its original label for the report.
    for (const auto& sample : samples) {
        const int area = sample.width * sample.height;
        const bool visible = sample.width > 0 && sample.height > 0;
        if (!visible) { continue; } // Empty rows do not belong in the result.
        areas.push_back(area);
        std::cout << sample.label << " width " << sample.width << " height " << sample.height;
        std::cout << " area " << area << '\n';
    }
    // Sort the values before choosing the middle entry and printing the total.
    std::sort(areas.begin(), areas.end());
    const auto total = std::accumulate(areas.begin(), areas.end(), 0);
    const auto middle = areas.empty() ? 0 : areas[areas.size() / 2];
    std::cout << "total " << total << " middle " << middle << '\n';
    // A copy keeps the source vector intact while the display order is reversed.
    auto reversed = areas;
    std::reverse(reversed.begin(), reversed.end());
    for (const int value : reversed) { std::cout << value << ' '; }
    std::cout << '\n';
    // Every number and label on this page is disposable synthetic lab content.
    return total > 0 ? 0 : 1;
}

Implements the corpus and performance tools for #1428, against feat/text-recognition.

The scorer compares captured text after Unicode NFC normalization and whitespace collapsing, with case preserved. It reports exact character edit distance for each image, median character error rate for each target class, and occurrence-counted exact matches for URLs and email addresses at eleven pixels and above. Distribution Tesseract can be measured immediately, without building put.gd. The same scorer accepts helper JSON later. Receipts identify the images, transcripts, engine version, language data hash, segmentation mode, and scaling method.

A QR code, short for quick-response code,[1] is a type of two-dimensional matrix barcode invented in 1994 by Masahiro Hara of the Japanese company Denso Wave for labelling automobile parts.[2][3] It features white ("0") and black ("1") squares in a square grid featuring fiducial markers on the corners, readable by imaging devices like cameras, and processed using Reed–Solomon error correction until the image can be appropriately interpreted. The required data is then extracted from patterns that are present in both the horizontal and the vertical components of the QR image.[4]

Whereas a barcode is a machine-readable optical image that contains information specific to the labeled item, the QR code contains the data for a locator, an identifier, and web tracking. To store data efficiently, QR codes use four standardized modes of encoding: numeric, alphanumeric, byte or binary, and kanji.[5] Compared to standard UPC barcodes, the QR labeling system was applied beyond the automobile industry because of faster reading of the optical image and greater data-storage capacity in applications such as product tracking, item identification, time tracking, document management, and general marketing.[4]
