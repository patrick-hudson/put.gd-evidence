Implements the corpus and performance tools for #1428, against feat/text-recognition.

The scorer compares captured text after Unicode NFC normalization and whitespace collapsing, with case preserved. It reports exact character edit distance for each image, median character error rate for each target class, and occurrence-counted exact matches for URLs and email addresses at eleven pixels and above. Distribution Tesseract can be measured immediately, without building put.gd. The same scorer accepts helper JSON later. Receipts identify the images, transcripts, engine version, language data hash, segmentation mode, and scaling method.
