usage: /home/lab/magpie-probe [options]

Command-line options (e.g. "--wayland-extensions=wl_shell").

Environment variables capitalise long form with prefix "MIR_SERVER_" and "_" in place of "-".
(E.g. "MIR_SERVER_WAYLAND_EXTENSIONS=wl_shell")

Config file entries are long form (e.g. "wayland-extensions=wl_shell").
The config file (magpie-probe.config) is located via the XDG Base Directory Specification.
($XDG_CONFIG_HOME or $HOME/.config followed by $XDG_CONFIG_DIRS)

                                        Tags can be specified by their full 
                                        heirarchy (e.g. “base/graphics”) or
