## H2 failure and control

Candidate random trial 8: operation `e4f2bf03-05d2-4ac3-8877-9ffa1cfafbee`, first motion at 1709 ms, pause at **76.681 ms**, **one ordinary pointer command afterwards, zero corrections**, first click **false**. A later API Stop retained 720 px. This is a failed first click, not a successful click inferred from the final `stopped` end reason.

Published-nightly matching-delay recheck [b/failure-recheck.jsonl](b/failure-recheck.jsonl): requested 1.709 s, measured 1.734 s, first click false, no pause, 13 ordinary pointer commands afterwards, `lost_track` at 720 px. The same row therefore fails on the published nightly and is not demonstrated to be a new PR regression. Ten additional random-start nightly trials are retained. The candidate's inherited open-loop random threshold (at least 9/10) is met, while the miss remains explicit.

The first progress tally incorrectly said 10/10. A complete audit of every raw `stoppedByClick` value found trial 8 was false. The raw export audit corrected the report to 9/10, and the guest was restarted for the nightly comparison before guarded retirement. No candidate retry replaced the failed trial.
